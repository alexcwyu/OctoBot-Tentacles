Design decisions

Decision Rationale Tradeoff Evidence
Keep concrete strategies/exchanges/UI as installed plugins. Reuse host evaluator/trading/service abstractions while extending concrete formulas and venue behavior. Installation/version activation determines which plugins runtime imports. RSIMomentumEvaluator.evaluate (L103) / Binance.order_request_kwargs_factory (L290) / WebInterface._async_run (L230)

Workflow

Installed plugin signal-to-order flow

OctoBot host constructs/subscribes plugins, Evaluators owns matrix/channels and Trading owns execution/portfolio/order state. Separate callback stages are not a direct RSI→DailyTradingMode call.

Diagram source
flowchart TD
  W0["Host OHLCV callback fetches candles and computes RSI evaluation."]
  W1["Host matrix callback aggregates valid technical/social/realtime values."]
  W0 --> W1
  W2["Producer averages strategy notes and submits state transition through host channel."]
  W1 --> W2
  W3["Consumer obtains host pre-order data and builds spot/futures order requests."]
  W2 --> W3
  W4["Host routes requests through concrete exchange overrides."]
  W3 --> W4
  1. Host OHLCV callback fetches candles and computes RSI evaluation.. RSIMomentumEvaluator.ohlcv_callback (L96) / RSIMomentumEvaluator.evaluate (L103)
  2. Host matrix callback aggregates valid technical/social/realtime values.. SimpleStrategyEvaluator._trigger_evaluation (L132)
  3. Producer averages strategy notes and submits state transition through host channel.. DailyTradingModeProducer.set_final_eval (L988) / DailyTradingModeProducer._set_state (L1048)
  4. Consumer obtains host pre-order data and builds spot/futures order requests.. DailyTradingModeConsumer.create_new_orders (L548)
  5. Host routes requests through concrete exchange overrides.. Binance.order_request_kwargs_factory (L290)

Strengths and limits

Strengths

  • Reviewed pipeline keeps concrete formulas, aggregation and order-producing modes separate across real host matrix/channel boundaries. RSIMomentumEvaluator.evaluate (L103) / SimpleStrategyEvaluator._trigger_evaluation (L132) / DailyTradingModeProducer.set_final_eval (L988) / DailyTradingModeProducer._set_state (L1048)

Limitations

  • Shipped market-making mode explicitly disables backtesting; generic bundle-wide backtesting claims need qualification. MarketMakingTradingMode.is_backtestable (L237)
