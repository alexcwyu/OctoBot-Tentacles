# Migration Guide: OctoBot-Tentacles

**Branch**: `feature/ayu_develop`
**Standard**: See `docs/PYTHON_MODERN_STANDARD.md` in the trading workspace root.

## Overview

This project has been modernized on the `feature/ayu_develop` branch to use the 2026 Python tooling stack. When syncing from upstream (default branch), the following changes must be re-applied if upstream overwrites them.

## What Changed

### 1. Build System (pyproject.toml)
- **Build backend**: `hatchling` (was: none -- no build system existed)
- **PEP 621 metadata**: All project metadata in `[project]` table
- **Dependencies**: Managed by `uv`, lockfile in `uv.lock`

### 2. Removed Legacy Files
The following files were removed (upstream may re-add them on sync):
- `.coveragerc`

If these reappear after a sync, delete them again. All configuration is in `pyproject.toml`.

### 3. Source Layout
- **Layout**: `src/` layout
- **Packages moved**: `Automation/`, `Backtesting/`, `Evaluator/`, `Meta/`, `Services/`, `Trading/` -> `src/octobot_tentacles/`
- **Import**: `import octobot_tentacles`

If upstream adds files to the old locations (root-level `Automation/`, `Backtesting/`, etc.), move them to `src/octobot_tentacles/`.

**Note**: This project uses OctoBot's tentacle manager plugin system. The `__init__.py` files in tentacle subdirectories are auto-generated by OctoBot and are gitignored. The src/ layout provides standard Python packaging while maintaining the tentacle directory structure within `src/octobot_tentacles/`.

### 4. Tooling Configuration (in pyproject.toml)

#### Ruff (linting + formatting)
```toml
[tool.ruff]
line-length = 88
target-version = "py313"

[tool.ruff.lint]
select = ["E", "W", "F", "I", "UP", "B", "SIM", "C4", "RUF", "PERF", "TC", "PTH"]
ignore = ["E501"]

[tool.ruff.lint.per-file-ignores]
"tests/*" = ["S101"]
"__init__.py" = ["F401"]

[tool.ruff.lint.isort]
known-first-party = ["octobot_tentacles"]
```

#### Pyright (type checking)
```toml
[tool.pyright]
pythonVersion = "3.13"
typeCheckingMode = "basic"
```

#### Pytest
```toml
[tool.pytest.ini_options]
minversion = "9.0"
addopts = ["-ra", "-q", "--strict-markers", "--import-mode=importlib"]
testpaths = ["tests"]
pythonpath = ["src"]
xfail_strict = true
filterwarnings = ["error"]
```

### 5. Python Version
- `.python-version` set to `3.13`
- `requires-python = ">=3.13"` in pyproject.toml

## After Upstream Sync Checklist

When merging upstream changes into `feature/ayu_develop`:

1. **Delete re-added legacy files**: `.coveragerc`, `setup.py`, `setup.cfg`, `requirements.txt`
2. **Check pyproject.toml**: Upstream may add a pyproject.toml. Keep `[build-system]`, `[tool.ruff]`, `[tool.pyright]`, `[tool.pytest]` sections intact.
3. **Check source layout**: If upstream adds new tentacle modules to the old root-level locations, move them to `src/octobot_tentacles/`.
4. **Re-lock**: Run `uv lock` to update `uv.lock` with any new/changed dependencies.
5. **Verify**: Run `uv sync && uv run python -c "import octobot_tentacles" && uv run pytest` (if tests exist).

## Quick Commands

```bash
uv sync                                              # Install all deps
uv run python -c "import octobot_tentacles"           # Verify import
uv run pytest                                         # Run tests
uv run ruff check .                                   # Lint
uv run ruff format .                                  # Format
uv lock                                               # Re-generate lockfile
```
